# Repair contract

The new horizontal gap adjustment applies at pre-save normalization with an explicit section ID and `visualCompositionVersion: 1`. The row must contain a directly undersized semantic control and exceed its available width after target expansion. The largest allowed smaller gap that fits is selected, using pinned spacing when available, with a minimum gap of 4 px. If no gap fits, existing bounded stack and rejection rules apply. The repair preserves child order and 44 px minimums. A candidate is used only after recursive geometry checks and schema revalidation. Existing legacy and native QA paths remain active.

Evidence records a numeric tree path, semantic role, before and after sizes, and parent reflow. The plugin keeps the aggregate count in section timings. No raw provider response or copy is included in these measurements. A repaired section can be normalized again without changing its design.
