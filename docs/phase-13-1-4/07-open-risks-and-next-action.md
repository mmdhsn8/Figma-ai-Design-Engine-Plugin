# Open risks

1. Real Figma relative transforms, font wrapping and synchronous layout behavior can differ from the synthetic fixture. Verify in a disposable page.
2. Fixed parents with multiple clip findings, noneditable child types, horizontal overflow or incomplete coverage remain intentionally blocked. An existing edit can also prevent safe recovery.
3. Native verification is bounded and rereads after an attempted change. This phase does not implement a general predicted/actual per-node geometry engine or arbitrary repeated settling.
4. Completion does not certify visual quality. The real storefront needs separate human review.
