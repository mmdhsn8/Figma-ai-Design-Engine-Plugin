## Baseline support boundary

The general renderer (`src/plugin/renderer.ts`) supports native fills, images, vector icons, Auto Layout, typography, strokes, radius and effects. The Chat generation schema is narrower (`src/shared/design-generation.ts`): it cannot represent all properties available to the general renderer. This is a generation capability limit, not evidence of a silent Figma renderer drop for a valid supported property.

Brand Kit and Skill consumption is present in source: `prepareGeneratedDesign` resolves pinned semantic tokens and validates authorized assets; section prompts include bounded selected Skill guidance and required pattern IDs. Actual influence on the reported live screenshot is **NOT VERIFIED** because no model response, pinned revision trace or screenshot is available.
