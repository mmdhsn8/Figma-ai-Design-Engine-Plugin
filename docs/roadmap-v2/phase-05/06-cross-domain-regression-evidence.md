# Cross-domain regression evidence

The existing scripted Universal Chat suite covers education, booking, SaaS analytics, marine archive and other open-domain briefs using the same coordinator, provider parser, adapter, renderer, and executor. Native receipts and geometry now run on these paths. New fixtures reproduce incident geometry independently from historical screenshots.

The integration tests inject horizontal overflow after acknowledgement and check that the persisted screen remains rendered and unverified. They verify a three-screen Persian run, a body over 1000 px in a 390×844 viewport, editable text aligned right, and preserved selection. The existing lost-acknowledgement test exercises native replay using the saved program. Additional Desktop and crash boundaries remain in the acceptance plan.

The follow-up exercises three screens for a community instrument library through the same route, two native instances using one component master, text paint overflow with an in-bounds text box, native interruption before creation, and interruption during post-adoption verification. A separate scroll test grows a 1000 px body to 1200 px, leaves the viewport at 844 px, and records no further repair on repeat.

Completion tests simulate a Companion disconnect before a plan returns, a schema-valid checkpoint with a changed program, and restart with a built pending root before adoption. They check stable IDs or zero writes as appropriate. Text tests exercise a Persian non-joiner, Persian numerals and a Latin currency code in one editable layer, English font isolation, invalid Unicode, and failure before construction when Arabic-capable fonts are unavailable. Another test interrupts verification with an unresolved instance master and confirms the screen stays unverified.
