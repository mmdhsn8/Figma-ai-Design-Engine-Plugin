## Text, native and visual limits

The regression suite checks right-aligned Persian text, a mixed string containing Persian, Persian numerals and USD, script-aware fallback, missing-font stop behavior, editable text, text auto-resize, measured text bounds and painted overflow. It verifies a tall mobile body scrolls inside a clipped 390×844 viewport, while layout/overflow tests reject horizontal bleed and clipped text. Local component/instance fixtures resolve back to a stable native master across resume.

The Figma Plugin API does not expose a glyph-by-glyph shaping verdict. These fixtures verify text values, chosen font, alignment, editable nodes and measured bounds; optical shaping and live font substitution remain Desktop-only evidence. No external or licensed assets are claimed by the mocks.
