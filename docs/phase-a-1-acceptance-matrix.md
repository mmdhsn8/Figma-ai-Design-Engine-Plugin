stage, ledger and native acknowledgement state.

## Pre-edit route and state findings

- Primary navigation is already limited to Home, Chat, History and More.
- Chat history is scoped by Figma file/page; checkpoints are scoped by document/page/chat. Opening
  installs the saved state and exposes recovery controls but does not call resume automatically.
- Chat switching and deletion are guarded while chat/native operations are active. History deletion
  removes local metadata/checkpoint only; it does not delete Figma nodes.
- Task stages, ledger, acknowledgement status, failure category and safe diagnostic projection are
  already persisted. These are the source of progress truth; estimated mutation counts are not a
  trustworthy percentage.
- Created native nodes carry `fad.tool.task-id.v1`; logical refs and existing inspection summaries
  already validate page, type, parent, operation fingerprint and task ownership. The current
  `inspect_nodes` tool also registers refs/plugin data, so it must not be reused for a supposedly
  read-only Layers screen.
- More has two duplicate JSON destinations; global Settings and the More Settings card also
  duplicate access to the same Settings overlay. Remove redundant navigation only, not workflows.
- Automatic Model Restore & Health Check, Brand Kit Manager/Editor/Create and Skills Manager/Details/
  Add remain intentionally deferred. Existing manual connection/session behavior and smoke-test
  controls are not to be removed.
