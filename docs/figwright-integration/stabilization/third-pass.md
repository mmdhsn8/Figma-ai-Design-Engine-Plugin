## Remaining risks and Desktop acceptance

- **Confirmed fixes:** Wrong-screen false completion, stale cached checkpoint handshake, obsolete credential invalidating renewed Chat, unverified image dispatch, malformed native response timeouts, foreign readback acceptance, greeting-to-checkpoint coupling and RTL cross-axis alignment. Each has a fault reproduction or direct adapter regression.
- **Verified maintainability risks:** Repeated UI preflight was removed. The role/topology heuristic still compares saved siblings during preparation and can depend on response order. A stable project-level composition assessment deserves isolated design and tests before moving that guard.
- **Unverified P1 hypotheses:** Figma native and storage writes can still interleave across a real host crash. An edit between later readbacks can invalidate earlier evidence. Companion secure-store races and late failures in non-Chat provider paths require separate deterministic fault coverage. No unresolved P0 was confirmed in the examined paths.
- **Live-only P2 unknowns:** Persian glyph shaping and reading order, native Auto Layout reflow, Figma storage quotas, actual model layout decisions, screenshots and real image capabilities. The new checks inspect declared program structure and native mock results. They supply no evidence of professional visual quality in live Figma.
