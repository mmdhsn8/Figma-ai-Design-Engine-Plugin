## Pinned Figwright comparison

- **Pin:** tag `v0.8.0`, full source revision `458e3dfa5da5d5c53f1fd5334a35754ffb2a66ca`. The release page shows `458e3df`; the full revision is addressable in the retrieved raw batch sources. The v0.8.0 README states MIT © Roya. No upstream code was copied, so no third-party notice was added.
- **Batch semantics:** MCP schema `packages/mcp/src/tools/batch.ts` accepts ordered `{ tool, params }` operations and `$N` references. Plugin `packages/plugin/src/handlers/batch.ts` first captures inverses, then applies existing handlers; it rejects deletes or structure changes without a faithful inverse. This is partial rollback built from supported inverses, not a general Figma transaction guarantee.
- **Version skew:** v0.8.0 README explicitly warns that server/plugin releases can drift and an older handler can ignore a new argument while the write appears successful. Local UI and sandbox ship together in `dist/plugin.js` with the UI embedded, but former dirty IDs did not bind to source bytes; the new fingerprint closes that distinct local identity gap.
- **Grounding and visual review:** the pinned README points to `figma-build`; the skill retrieved at `main` recommends reusing variables/components/styles, parent-first Auto Layout, native readback and screenshots. Because the v0.8.0 skill body could not be fetched through the available source cache, this is treated as guidance only, not as pinned implementation evidence. The same ideas already exist in the local typed design context, renderer, native verification and optional visual-review path.
- **Security and license:** the v0.8.0 README describes the local relay boundary and calls out that write/export tools can alter files. README says MIT; direct reads of tag `LICENSE`, `SECURITY.md`, pinned `AGENTS.md`, and test-tree pages were blocked by the public source cache. No install scripts, dependencies, plugin, or external code were run or imported. This pass does not claim a complete upstream security-policy audit.
- **Release history:** v0.8.0 changelog includes batch references, text sizing, per-write undo behavior and multiple fixes for native Figma edge cases. That history supports a conservative conclusion: a batch acknowledgement is not native readback, and rollback safety must remain operation-specific.

No upstream code was adopted. The source lesson adapted is to treat build/version skew as an explicit protocol state and to verify what the native side actually returned. The local content fingerprint is a small implementation through existing build scripts; no new auth, ledger, renderer or service was added.
