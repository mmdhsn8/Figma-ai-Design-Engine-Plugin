# Limitations and FW-6 handoff

The correction allowlist covers one horizontal or vertical layout sizing assignment to one freshly rendered owned FRAME within an Auto Layout parent. Plugin readback must show a known original value and a deterministic DesignProgram target value. Styles, bindings, instance changes, text resizing, contrast edits, root replacement and recovered roots are outside this allowlist.

Provider availability and a visible consent mechanism remain prerequisites to external review. OAuth refresh and provider timeout behavior on a real image transport cannot be validated through the text-only chat contract. Preserve separate native and visual outcomes. A remaining unsupported finding keeps QA at `ISSUES_DETECTED`, including after a successful correction and second capture.

The local fake Figma runtime cannot establish image fidelity, Persian shaping, geometry fidelity, Desktop message sizes or memory behavior. Keep the gate off in the default build and verify F1 on disposable files under separate authorization before scaling up. FW-6 work has not been started.
