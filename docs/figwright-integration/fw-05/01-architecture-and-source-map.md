# FW-5 flow and source map

The prior path ended after capture metadata was saved. The application chat route accepts text input and cannot accept a privately scoped screenshot. A reviewer dependency with an exact grant supplies the missing decision. After an eligible decision, the existing plugin executor applies the correction and the same task owner records the outcome.

```text
Before: render → adopt → native readback → PNG → metadata checkpoint
After:  render → adopt → native readback → PNG → exact grant → reviewer
             → one typed correction → native readback → linked PNG → fresh grant
             → reviewer → existing checkpoint
```

| File | Completion changes |
|---|---|
| src/shared/fw5-visual-qa.ts, src/shared/fw5-visual-qa-feature.ts | Review and correction contracts, PNG limits and policy |
| src/shared/messages.ts, src/shared/universal-design.ts | Typed bridge messages and trace stage |
| src/plugin/main.ts, src/plugin/figma-tool-executor.ts | Route requests to the existing executor queue. Bind the repair to the original receipt and native plan |
| src/plugin/design-program-spike.ts, src/plugin/design-program-geometry.ts | Admit one eligible fresh sizing discrepancy provisionally. Include sizing in geometry receipts and accept legacy receipts on read |
| src/ui/App.tsx, src/ui/chat-task.ts, src/ui/task-native-bridge.ts | Route scoped capture and mutation messages. Forward optional reviewer and authorization dependencies |
| src/ui/universal-design-task.ts | Gate reviewer calls, record one repair attempt, compare readback and save metadata |
| tests/fw5-visual-qa.test.ts | Contracts, fake executor, bridge and task owner scenarios |

The first screenshot is permitted for a fully readback-confirmed root or a fresh root with exactly one eligible FW-4 sizing mismatch and complete readback coverage. The latter remains unverified until strict post-repair native readback. Only the existing task owner commits the screen. Recovery of an existing root bypasses visual recapture and correction. No Figwright source was incorporated.
