# Native components and layout

The storefront layout consumes shared catalog records and composes each role separately. Home has an editorial hero and a four-product grid that stacks when the content width falls below the two-column threshold. Detail starts with a hero image and three thumbnails, followed by options and information. Cart groups item details, stepper controls and a computed order summary. Horizontal visual order follows RTL and Latin size values remain editable.

The existing 390×844 native roots keep 20 px gutters and use vertical scrolling. The suite applies all nine ordered, bounded section transactions. Clip and scroll flags, repeated apply and touch geometry remain in the same renderer and native verification path. Figma Desktop font metrics, visible scroll behavior and clipping require live confirmation.

Repeated vector artwork is a native component instance. Definitions are deduplicated through the existing managed registry by artwork identity and size. The renderer preserves an existing master. Readback verifies the owned master, vector child and fill. Shared native paint and typography styles use a stable storefront namespace with separate pinned Brand Kit revisions and modes. Product cards and CTA or navigation labels remain editable native frames and text.
