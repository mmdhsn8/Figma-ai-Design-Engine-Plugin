# Generation and persistence

Chat still supplies the structured three-stage plan, selected model, task fingerprint and pinned design context. New eligible Moonwear drafts persist the local layout version and compose three sections per screen from the same catalog. The sections use the same parser, preflight, checkpoint save, native apply, verification and recovery path. The earlier model-driven path remains for other prompts and saved drafts.

The local path performs zero section provider calls. Chat planning retains its existing provider behavior. Scope, document and fingerprint checks continue before work, and diagnostics report the layout version and section preparation, rendering and verification times. The transaction ledger counts source nodes. Renderer-added artwork and label layers derive stable IDs from their parent instead of consuming source IDs.

Replay reads stored section content and retains the section and screen IDs. Cart item prices and quantities, shipping, discount, subtotal and total are calculated in integer toman and share the same merchandise prices displayed elsewhere.
