# Assets and art direction

The sample storefront uses original clothing illustrations. No images were downloaded and the asset summary lists these as disclosed fallbacks. Each vector instance can be edited through its source master, and the surrounding artwork frame and Persian disclosure remain separate native nodes. Main gallery, back view and textile artwork have distinct vector paths. Color follows the resolved style system.

The existing path for pinned Brand Kit visual assets remains available to the renderer. Supplied catalog content and asset requests use the existing model-driven path. There is no external image retrieval in this implementation.
